# traffic-camera-sources

Open dataset repo built ONLY from the livetrafficcam.com public API and
public pages. The private site repo is out of scope; never reference or
copy from it.

- `data/sources.json` and `docs/` (except `docs/states/`) are authored
  by hand. `data/cameras.geojson`, `data/uptime-summary.json`, and
  `docs/states/*.html` are generated by `scripts/refresh.mjs`; edit the
  script or `docs/state-template.html`, not the outputs.
- The API caps at 200 cameras per query; cameras.geojson is a disclosed
  sample. Fleet counts come from uptime-summary.json only.
- No images or image URLs in the data.
- No emojis. No commit-attribution trailers.
