traffic-camera-sources / MCP server

Query the data from an AI assistant

livetrafficcam-mcp is an MCP (Model Context Protocol) server over the same public API this dataset is built from. It gives assistants like Claude live answers instead of a static file: cameras on a route, cameras on a mountain pass, whether one camera is up right now, and a state's measured uptime.

Install

claude mcp add livetrafficcam -- npx -y livetrafficcam-mcp

Configuration for Claude Desktop and Cursor is in the repo README.

Tools

  • list_states: covered states with camera counts and liveness.
  • cameras_by_state: cameras for a state, optionally one route.
  • cameras_for_entity: cameras for a pass, corridor, bridge or tunnel, like Donner Pass.
  • camera_status: one camera's verified-live status and official source.
  • state_uptime: the state's row from the uptime report.
Data aggregated from official agency feeds by LiveTrafficCam.
