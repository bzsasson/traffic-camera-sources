traffic-camera-sources / How to cite

How to cite this dataset

The dataset is CC BY 4.0: use it freely, with attribution. Two rules keep citations honest:

  • Cite uptime numbers with a link to the live camera uptime report, where they are generated and kept current. Numbers in this repo are weekly snapshots and go stale.
  • Keep the per-camera agency attribution (for example "Camera: Caltrans") when displaying camera data.

Citation formats

Plain text:

Sasson, B. traffic-camera-sources: US traffic camera feed sources and
measured uptime. LiveTrafficCam.
https://bzsasson.github.io/traffic-camera-sources/

The repository carries a CITATION.cff, so GitHub's "Cite this repository" button produces BibTeX and APA directly.

DOI (all versions, resolves to the latest release):
10.5281/zenodo.22223825

What you are citing

The registry of official feed sources is authored by hand and maintained. The camera GeoJSON is a disclosed sample of up to 200 cameras per state (the source API caps each query); full per-state fleet counts live in the uptime summary. Liveness methodology: how liveness is measured.

Data aggregated from official agency feeds by LiveTrafficCam.
